## The problem

When I’m working, I check the time and the weather a lot. On my phone, that means seeing a notification, opening it, and losing focus. I wanted something that gives me the information at a glance and nothing else.

## What I built

A small round display that I can move around: on my work desk during the day and in my bedroom at night. Each place can have its own view.

- **Time, date and weather** in large type, readable from across the room. The weather updates every half hour.
- **A sky that follows the day:** the background changes from sunrise to day, sunset and night, timed by the real sunrise and sunset.
- **Focus timer:** swipe to a second view, drag a ring round the edge to set the minutes, and it beeps when time is up.
- **Night mode:** from 22:00 to 07:00 the screen dims to a soft red, so it doesn’t light up the bedroom. A tap brightens it.
- **Keeps time without the internet:** it syncs over Wi-Fi and has a clock chip to fall back on.
- **Burn-in protection:** the content moves a few pixels now and then so the screen doesn’t burn in.

## What I learnt

With this project I learnt electronics, 3D modelling and 3D printing. I modelled the case in 3D, printed it and fitted the board inside.

The firmware is written in C on ESP-IDF, with LVGL for the screen. I also built a desktop simulator that uses the same screen code, so I can work on the UI without flashing the device every time. The same C code also compiles to WebAssembly, which is how the [live demo](https://demo.aura.buddyfall.com) runs in the browser.

## Where it is now

The first version is on my desk and in use. Next: a separate view for each room, and maybe a speaker so it can be an alarm clock too.
